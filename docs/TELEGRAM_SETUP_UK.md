# Підключення Telegram-бота

## 1. Створіть бота

1. Відкрийте в Telegram **@BotFather**.
2. Надішліть `/newbot`.
3. Вкажіть довільне ім'я.
4. Вкажіть username, який закінчується на `bot`.
5. Збережіть токен, який надішле BotFather. Нікому його не пересилайте.

## 2. Дозвольте читати повідомлення

Для звичайної групи:

1. У **@BotFather** надішліть `/setprivacy`.
2. Виберіть свого бота.
3. Натисніть **Disable**.
4. Додайте бота до групи.

Для Telegram-каналу просто додайте бота як адміністратора. Дозволу на публікацію
повідомлень достатньо, щоб працювали команди у каналі; для самого зчитування бот
має отримувати дописи каналу.

## 3. Додайте токен і запустіть

У папці `/workspace/scaner`:

```bash
cp .env.example .env
```

У файлі `.env` заповніть один рядок:

```dotenv
TELEGRAM_BOT_TOKEN=токен_від_BotFather
```

Потім:

```bash
uv sync --extra dev --frozen
uv run ticker-bot
```

У вікні має з'явитися повідомлення `Telegram bot polling started`.

## 4. Перевірте

1. Надішліть у групу `AAPL $NVDA NASDAQ:TSLA`.
2. Надішліть `/today`.
3. Бот має показати три тікери.
4. Надішліть `/export`, щоб отримати CSV-файл.

Якщо бот бачить команди, але не бачить звичайні повідомлення, поверніться до
`/setprivacy` у BotFather і переконайтеся, що обрано **Disable**.

Якщо бот зовсім не відповідає, перевірте, що запущена лише одна копія застосунку
з цим токеном і що бот доданий до правильного чату.
