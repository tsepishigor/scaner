# Telegram Scanner

Перша робоча версія приватного сканера акцій. Бот мовчки читає нові повідомлення у
Telegram-групі або каналі, знаходить тікери й одразу додає їх на вебсторінку.

Відкрийте адресу застосунку в браузері — сканер знаходиться на головній сторінці
`/`. Якщо Telegram ще не передав жодного тікера, там показуються п'ять прикладів.

> Тікери з Telegram уже реальні. Ціни, обсяги та свічки в цій версії є стабільними
> демонстраційними даними. Їх замінить Polygon після додавання ключа.

## Що вміє сканер

- показує акції, які бот отримав із Telegram за вибрану дату;
- відображає свічковий графік на інтервалах від 1 хвилини до 1 дня;
- фільтрує за ціною, зміною, обсягом, RVOL і Float;
- залишає одним перемикачем лише акції, які пройшли всі задані умови;
- зберігає для кожної акції оцінку від 1 до 5 і особисту нотатку;
- дає переглядати попередні дні;
- автоматично оновлює список, поки сторінка відкрита.

## Що вже вміє бот

- розпізнає `AAPL`, `$NVDA`, `NASDAQ:TSLA`, `BRK.B` і `BRK-B`;
- читає звичайний текст і підписи до фото/файлів;
- працює з групами, супергрупами та каналами;
- не дублює тікер, якщо Telegram повторно доставив те саме повідомлення;
- оновлює дані після редагування повідомлення;
- рахує день за часовим поясом `Europe/Kyiv`;
- зберігає тільки тікер, ID чату/повідомлення та час — без текстів і даних авторів;
- віддає список майбутньому скрінеру через локальне HTTP API.

## Як підключити завтра — коротко

1. У Telegram відкрийте **@BotFather** і виконайте `/newbot`.
2. Скопіюйте виданий токен. Не публікуйте його й не додавайте в Git.
3. Для групи в **@BotFather** виконайте `/setprivacy`, виберіть бота й натисніть
   **Disable**. Для каналу додайте бота адміністратором.
4. У папці проєкту виконайте:

   ```bash
   cp .env.example .env
   ```

5. Відкрийте `.env` і вставте токен після `TELEGRAM_BOT_TOKEN=`.
6. Запустіть:

   ```bash
   uv sync --extra dev --frozen
   uv run ticker-bot
   ```

7. Додайте бота в потрібний чат і надішліть `AAPL $NVDA`. Команда `/today`
   повинна показати обидва тікери.

Ще простіша покрокова пам'ятка є у
[docs/TELEGRAM_SETUP_UK.md](docs/TELEGRAM_SETUP_UK.md).

> Бот бачить нові дописи тільки після підключення. Історію старих повідомлень
> Telegram автоматично йому не передає.

## Простий запуск на Windows

Розпакуйте ZIP у звичайну папку та відкрийте файл `START_SCANNER.bat` подвійним
кліком. Під час першого запуску він сам завантажить усе потрібне, попросить токен
Telegram-бота й відкриє сканер за адресою `http://127.0.0.1:8765`.

Нічого встановлювати вручну не потрібно. Вікно запуску не закривайте, поки
користуєтеся сканером. Для зупинки просто закрийте це вікно.

## Команди

- `/today` — тікери та кількість згадок за сьогодні;
- `/stats` — коротка статистика;
- `/export` — CSV-файл за сьогодні;
- `/chatid` — ID поточного чату;
- `/help` — підказка.

Бот не відповідає на кожен знайдений тікер, тому не засмічує робочий чат.

## Обмежити доступ одним чатом

Спочатку залиште `ALLOWED_CHAT_IDS` порожнім, додайте бота й виконайте `/chatid`.
Потім вставте отримане число у `.env`, наприклад:

```dotenv
ALLOWED_CHAT_IDS=-1001234567890
```

Для кількох чатів вкажіть ID через кому. Після зміни перезапустіть застосунок.

## API сканера

Поки застосунок працює, список тікерів доступний тут:

```text
http://127.0.0.1:8765/api/v1/tickers
```

Можна вибрати дату й чат:

```text
http://127.0.0.1:8765/api/v1/tickers?day=2026-10-12&chat_id=-1001234567890
```

Перевірки стану: `/healthz` та `/readyz`. Інтерактивна документація: `/docs`.
За замовчуванням API слухає лише локальний комп'ютер. Якщо його колись потрібно
буде відкрити назовні, спочатку задайте секрет `SCANNER_API_TOKEN`.

## Розробка і перевірка

```bash
uv sync --extra dev --frozen
uv run pytest
uv run ruff check .
uv run ruff format --check .
```

API можна перевірити без Telegram-токена:

```bash
BOT_ENABLED=false uv run ticker-bot
```

Дані зберігаються у `data/tickers.db`. Файли `.env` і бази даних виключені з Git.

## Docker (необов'язково)

Після створення `.env`:

```bash
docker compose up --build -d
docker compose logs -f ticker-bot
```

Не запускайте одночасно дві копії бота з одним токеном: Telegram дозволяє лише
один polling-процес.
